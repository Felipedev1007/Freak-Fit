# UI Components

Componentes compartilhados organizados por uso:

- `actions`: botoes e toggles.
- `forms`: inputs, labels, selects e controles de formulario.
- `feedback`: alertas, loaders, progresso e toasts.
- `layout`: estrutura visual e containers.
- `navigation`: breadcrumbs, paginacao e tabs.
- `overlays`: dialogs, sheets, popovers e tooltips.
- `menus`: menus, command palette e navegacao menu.
- `display`: avatar, badge, chart, skeleton e table.
- `media`: imagens, carousel e aspect ratio.
- `disclosure`: accordion e collapsible.
